# Module 2: Computer Fundamentals

## 🎯 Key Concepts Learned
- **Inside a Computer:** CPU, RAM, Storage, and Motherboard.
- **Client-Server Model:** The foundation of how data travels from web servers to user browsers.
- **Virtualization:** Running isolated environments (VMs) like Kali Linux safely on a host machine.
- **Cloud Computing:** Basics of shared responsibility and cloud infrastructure.

- Used interactive diagrams to understand hardware architecture.
- Grasped the concept of why Virtual Machines are essential for safely testing malware and pentesting tools.
