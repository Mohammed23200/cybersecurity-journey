# Module 1: Introduction to Cyber Security

## 🎯 Key Concepts Learned
- **Offensive Security (Red Team):** Breaking into systems to find vulnerabilities (e.g., Ethical Hacking).
- **Defensive Security (Blue Team):** Monitoring, detecting, and responding to threats (e.g., SOC Analyst).
- **Careers in Cyber:** Explored roles like Penetration Tester, AppSec Engineer, and GRC.

## 🧠 Deeper Understanding
- Security is not just about tools; it's a mindset. To build secure applications (AppSec), I must understand how attackers exploit them (Pentesting).
